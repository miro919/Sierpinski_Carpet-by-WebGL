# WebGL Sierpinski Carpet

WebGL을 이용하여 구현한 시에르핀스키 카펫(Sierpinski Carpet)입니다.  
시에르핀스키 삼각형의 사각형 버전으로, 정사각형을 3×3으로 분할하고
중앙 영역을 제외하는 과정을 반복하여 구현했습니다.

## 소스 코드 및 실행 파일

- HTML: `WebGL_Carpet/angelChap2/gasket2.html`
- JavaScript: `WebGL_Carpet/angelChap2/gasket2.js`
- WebGL 공통 라이브러리: `WebGL_Carpet/Common/`

실행 결과 파일: angelChap2의 `gasket2.html`
